# The Complete Workout Plan Framework

---

## 1. Client Assessment (Non-Negotiable Before Anything)

You don't write a single exercise before this is done.

**Health & Safety Screen**

- PAR-Q form (flags conditions that need medical clearance)
- Injury history, chronic conditions, joint limitations
- Medications that affect training (heart rate meds, etc.)

**Physical Baseline**

- Age, weight, height, body fat estimate if possible
- Training experience: beginner / intermediate / advanced
- Movement screen: overhead squat test to spot mobility gaps, imbalances, postural issues
- Daily activity level (desk job vs. physical job changes everything)

**Lifestyle Factors**

- Sleep quality and quantity
- Stress levels (high stress = lower recovery capacity = less volume)
- Available equipment: full gym / home / kettlebells only
- Realistic training days per week

**Goal Clarification — SMART Format**
Vague goal = garbage plan. Force specificity:

| Vague          | SMART                               |
| -------------- | ----------------------------------- |
| "Lose weight"  | Lose 8kg in 12 weeks through recomp |
| "Get stronger" | Add 20kg to deadlift in 8 weeks     |
| "Get fit"      | Run 5km without stopping in 6 weeks |

---

## 2. Determine Training Split & Frequency

| Experience    | Days/Week | Best Split         |
| ------------- | --------- | ------------------ |
| Beginner      | 3 days    | Full Body          |
| Intermediate  | 4 days    | Upper / Lower      |
| Intermediate+ | 5 days    | Push / Pull / Legs |
| Advanced      | 5–6 days  | PPL or Hybrid      |

**Default for 90% of clients:** Full Body 3x/week + dedicated cardio days. More days ≠ better results. Recovery is where adaptation happens.

---

## 3. Session Structure — Every Single Workout

```
1. Warm-Up          (5–10 min)  → dynamic mobility + activation
2. Compound Lifts   (20–30 min) → movement patterns, heavy
3. Accessory Work   (15–20 min) → isolation + weak points + core
4. Cardio Finisher  (0–15 min)  → only if goal = fat loss
5. Cool-Down        (5–10 min)  → static stretching, 30s+ holds
```

---

## 4. Build Around Movement Patterns (Not Muscle Groups)

This is how elite coaches think. Every session should hit 3–4 of these:

| Pattern               | Primary Muscles     | Examples                              |
| --------------------- | ------------------- | ------------------------------------- |
| **Hinge**             | Posterior chain     | Deadlift, RDL, KB swing               |
| **Squat**             | Quads, glutes       | Goblet squat, back squat, split squat |
| **Push (horizontal)** | Chest, triceps      | Bench press, push-up                  |
| **Push (vertical)**   | Shoulders           | Overhead press                        |
| **Pull (horizontal)** | Back, biceps        | Row variations                        |
| **Pull (vertical)**   | Lats                | Pull-up, lat pulldown                 |
| **Carry / Core**      | Full body stability | Farmer carry, plank, dead bug         |

Hitting patterns ensures no muscle group is chronically missed or overloaded.

---

## 5. Sets, Reps & Intensity by Goal

| Goal        | Sets | Reps  | Rest    | Intensity                |
| ----------- | ---- | ----- | ------- | ------------------------ |
| Strength    | 4–5  | 3–6   | 2–4 min | 80–90% 1RM               |
| Hypertrophy | 3–4  | 8–12  | 60–90s  | 65–75% 1RM               |
| Fat Loss    | 3–4  | 10–15 | 30–60s  | Moderate, higher density |
| Endurance   | 2–3  | 15–20 | 30s     | Light–moderate           |

**For beginners:** Always start at the lower end of sets. 1–2 reps in reserve — never train to failure in early weeks.

---

## 6. Weekly Volume Per Muscle Group

Too little = no adaptation. Too much = breakdown. Stay in these ranges:

| Experience Level | Sets Per Muscle Group / Week |
| ---------------- | ---------------------------- |
| Beginner         | 8–12 sets                    |
| Intermediate     | 10–16 sets                   |
| Advanced         | 12–20 sets                   |

If progress stalls → adjust volume first, not random exercise swaps.

---

## 7. Cardio Programming — Both Types Required

| Type                 | Intensity     | Duration  | Frequency     | Purpose                               |
| -------------------- | ------------- | --------- | ------------- | ------------------------------------- |
| **Zone 2 / LISS**    | 60–70% max HR | 30–60 min | 3–5x/week     | Aerobic base, fat oxidation, recovery |
| **HIIT / Intervals** | 85–95% max HR | 15–20 min | 1–2x/week MAX | Conditioning, metabolic boost         |
| **Daily Steps**      | Easy walking  | All day   | Daily         | Fat loss lever, NEAT                  |

**Critical rule:** Fat loss = diet + 8–12k daily steps + consistency. Not killing clients with HIIT every session.

**Placement rule:** HIIT only on non-heavy-lift days or after lifting — never before compounds.

---

## 8. Progressive Overload — Built Into the Plan, Not an Afterthought

Ways to progress (in order of priority):

1. Add reps within the target range
2. Add small weight increments
3. Add a set
4. Decrease rest time (increase density)
5. Upgrade to a harder movement variation

**8-Week Progression Model:**

| Week | Focus                                          |
| ---- | ---------------------------------------------- |
| 1–2  | Movement quality, moderate load                |
| 3–4  | Add reps or small weight increases             |
| 5–6  | Add volume (extra set per compound)            |
| 7    | **Deload** — cut volume 40–50%, keep intensity |
| 8    | Retest benchmarks, reset at higher baseline    |

---

## 9. Nutrition Integration

| Variable             | Guideline                             |
| -------------------- | ------------------------------------- |
| Protein              | 0.7–1g per lb of bodyweight           |
| Fat loss deficit     | 300–500 kcal below maintenance        |
| Muscle gain surplus  | 200–300 kcal above maintenance        |
| Hydration            | ~0.5x bodyweight in oz of water daily |
| Protein distribution | Spread across meals — not one big hit |

## 10. Sample Weekly Structure (Beginner Recomp, 4 Training Days)

| Day | Session           | Detail                           |
| --- | ----------------- | -------------------------------- |
| Mon | Full Body A       | Squat + Bench + Row + Core       |
| Tue | Zone 2 Cardio     | 30 min easy run/walk + mobility  |
| Wed | Full Body B       | Hinge + OHP + Pull-up + Core     |
| Thu | Rest / Walk       | 8–10k steps, light stretch       |
| Fri | Full Body C       | Split squat + Push + Row + Carry |
| Sat | Zone 2 + Mobility | 35 min + hip/shoulder work       |
| Sun | Full Rest         | Sleep, eat, recover              |

---

## 11. Tailoring Adjustments by Client Variable

| Situation                | What to Adjust                                           |
| ------------------------ | -------------------------------------------------------- |
| Low fitness baseline     | Lower volume, longer rest, simpler movements             |
| Joint pain               | Swap barbells → dumbbells/cables/kettlebells, never skip |
| High stress / poor sleep | More Zone 2, less HIIT, reduce total volume              |
| Time-poor client         | Supersets, 45-min dense sessions                         |
| Fat loss plateau         | Increase steps first, then reassess calories             |
| Strength plateau         | Deload, then reset with higher intensity                 |
| Beginner overwhelm       | Cut to 3 movements per session, master them              |

---

## 12. Monitoring & Reassessment Cycle

A plan without feedback is just a guess.

**Weekly:**

- Check-in on fatigue, soreness, sleep, adherence
- Adjust volume or intensity based on feedback

**Every 4–6 Weeks:**

- Repeat movement screen
- Retest strength benchmarks
- Reassess body composition
- Update goals if needed
- Evolve the plan — same program forever = zero progress

---

## The Core Principle

> **Assess → Structure around patterns → Load with purpose → Progress systematically → Recover hard → Reassess → Repeat**

Everything else — exercises, splits, cardio type — is a variable you adjust based on who's in front of you.
